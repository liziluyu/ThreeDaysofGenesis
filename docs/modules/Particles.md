# 粒子类型行为细则

各类型权威契约见 `docs/ParticleTypeInterface.md`；本文件是各类型行为的工作摘要。类型清单与注册顺序见 `docs/modules/SimulationCore.md`。

当前类型：石头 / 沙 / 土 / 湿土 / 水 / 大气 / 草种子 / 草 / 花 / 腐殖质 / 腐殖土 / 湿润腐殖土 / 水生植物 / 火 / 树木种子 / 树干 / 树叶 / 雷电 / 生物质 / 冰（蒸汽与云已并入湿度场，不再是粒子）。

## 土与湿土

一对双向反应（走 `ParticleIds`）：干土正上方是水时喝掉那格水变湿土；湿土 = 干土 + 一份水，自己搬运这份水。

- 常温（T < 60°）**有压才渗**：正上方是水或湿土（水头压力）才以每逻辑帧 50% 概率把水交给邻格干土（正下方优先，被挡按随机序改试同行左右 = 侧向渗流；先判压再判目标再摇骰，RNG 消耗不随湿土格数漂移）。
- **孤立湿土（上方是空气）永久持水**（田间持水量）。
- 受热（≥ 60°）改往上送：上方干土则 50% 润湿；上方空气且没饱和则摊一份水汽进空气（不可见）并吸走一份相变潜热。都送不出去就保持湿。
- 水迁移带 `T(源)×1.2` 的热量（1.2 = 湿土热容 2.0 − 干土热容 0.8），两侧温度不跳。水总量（水格 + 湿土格 + 湿度场）全程守恒；只有干土接得住水。

## 草种子

受重力固体粉末（摩擦/粘性 0.5）。**随机刻**命中：

1. 先看正上方两格：全是水且正下方是软底（土/湿土/腐殖土/湿润腐殖土/沙）⇒ **沉水**——吸收头顶那格水、发芽成 1 格水生植物。
2. 否则八邻有湿土或腐殖土时，把自己与上方 1-3 格（`NextInt` 随机高度）替换为草、遇固/液即停——**腐殖土为决定性条件**（八邻没有真湿土）时发芽成功会在同一随机刻消耗脚下连续土层里最深一格腐殖土家族（`HumusSoil→Soil`/`WetHumusSoil→WetSoil`，`SetPhase` 保水保热）；八邻已有真湿土不消耗。发芽后另有 **30%** 概率把株顶那格草 `SetPhase` 成花。
3. 先判邻居后摇高度；两条路都无资格时不消耗随机数，累计「空转」命中，连续 3 次无发芽条件直接 `SetPhase` 成腐殖质（计数在 flags bit5-6）。

## 草

固体（非 `IsStatic`——静态类型收不到随机刻；靠空 `OnMotion` 定植）。`LightAbsorption` = 0.8。

- **逻辑帧衰老**：年龄 = `Cell.shade` × `TicksPerShadeStep`(10) + flags bit3-6 余数（`CellFlags.GrassAgeRemainderMask`），每逻辑帧 +1、每 10 帧 `shade` 推进一档（调色板深绿 (58,124,50) → 黄绿 (170,178,66)，`OnSpawn` 钉成 0 ⇒ 越老越黄），年龄到 `LifespanTicks`（2400 ≈ 120 秒）寿终 `Clear`。衰老不耗随机流、不读邻居、不移动、不写 Q。
- **随机刻**按顺序判三种死法（都走 `Clear`、各按世界 20% 规则留腐殖质）：
  1. 正上方是固体或液体且非同一株（草/花）→ 被压死，死亡沿竖直向下传播清整段；
  2. 正下方不是土/湿土/腐殖土/湿润腐殖土（也不是同株下段）→ 失去扎根而死，向上传播清整段；
  3. 温度 > 50 或 < 3 → 这一格死（脚下是腐殖土家族时放宽为 > 55 / < 0；**普通窗口必死、腐殖土窗口存活**时存活并消耗脚下土层最深一格腐殖土家族）。
- 随机刻 15% 概率在半径 2 圆盘内找第一个「下方 1 格是可托住种子的固体（固体且非同株）的空地」撒新草种子，随后把半径 2 内第一个沙 `SetPhase` 成土。

## 花

草株顶端的显色格（发芽时 30% 概率株顶变花）。**继承草的全部性质**（Solid | Organic、定植、热容 0.8 / 导热 0.6 / 辐射 1.0 / 光吸收 0.8、三条随机刻死法同判据同顺序、可燃）。差别：颜色 + **不衰老**（`OnLogic` 严格空体 ⇒ `hasLogic: false`，`shade` 是花色而非年龄档）、**不撒种/不固沙**。花色 = 12 色调色板由世界在 `Set`/`SetPhase` 时均匀抽样，`OnSpawn` 不覆写 ⇒ 每朵随机、终生不变。不占 flags 私有位。与草互为同一株（互不算压、互为扎根、级联一起清）。

## 腐殖质 / 腐殖土 / 湿润腐殖土

- 腐殖质：每逻辑帧把八邻第一个土壤变成腐殖土后自己消失。
- 腐殖土：随机刻命中且正上方是腐殖质时，半径 2 内从近到远找第一个普通/湿润土壤改良（→腐殖土/湿润腐殖土，水跟物质走）并吸收上方腐殖质——腐殖土向外扩张。
- 湿润腐殖土逻辑与湿土逐条同构（受热上行/有压才渗/孤立持水，带 T(源)×1.2 的热）。
- **植物优待（消耗型）**：草种子八邻有腐殖土家族即视同湿土发芽、喜湿树木（杨/橡/柳）认它为合格基质、草/花脚下是它时温度致死窗口放宽——但植物真正靠它存活/发芽（腐殖土是决定性条件）时，把脚下连续土层里**最深**一格腐殖土家族退化成普通土（`SetPhase` 保水保热）：**植物受益即耗肥**。

## 水生植物

由草种子沉水发芽而来。**每格植物 ⇔ 一格水**——四种死法都把该格还成水、被固体压埋时注入湿度场，不带 Organic。

- 植物随机刻逐格生长（头顶是水且上方还有一格保命水）；**无株高上限**（2026-10-17）：会一直长到**水面下一格**，只剩一格水即永久停（水账仍 1:1）；1 格宽水道里中间茎格仍会被「八邻无液体」逐格修剪。10% 概率撒种时水位 +1、水格变种子、基质不消耗。
- 逻辑帧衰老（同草模式：年龄 = `shade`×5 + flags bit3-5 余数、每 5 帧推进一档 ⇒ 越老越黄、1200 逻辑帧寿终 `SetPhase` 还水，`OnSpawn` 钉 `shade` = 0）。

## 火

气体、第一个粒子级热源。每逻辑帧按八邻重判**附着火**（有固/液；火焰不算附着物）/**游离火**（无固/液，即火舌）：

- 附着火定在原地：接触点燃邻接草/花/树叶/树干（八邻、优先级链 草/花 1/20 > 树叶 1/20 > 树干 1/60、每逻辑帧恰摇一骰——有草/花时绝不摇叶/干的骰；**有燃料就不摇熄灭骰**，邻接燃料必被逐格吃掉；树也是燃料 ⇒ 森林火灾涌现，火沿树冠蔓延、烧断树干中段后上段级联倒下；注意树干 T > 50° 热致死通常比 1/60 先到）。本格火温 ≥ 60° 才烤干邻接湿土/湿润腐殖土、潜热 −1.2T 结算（水汽走湿度场守恒）。本格温度 < 400 时注热 250。正上方是气体且 T ≥ 200 时 1/10 抛射火舌。
- **熄灭档位互斥**：正下方石头/沙/液体（压顶）→ 当帧立灭 > 被包围（八邻全无空气/气体且无燃料）→ 当帧窒息立灭 > 游离火 T < 40 当帧立灭 > 游离火 1/8 > 有燃料不摇 > 贴液体 1/2 > 贴任何非可燃固体 1/5（石头/沙/湿土/干土/腐殖类/种子全在内，草/花/树叶/树干除外；旧的「附着无燃料 1/120」已删）。
- 游离火不注热、`OnLogic` 末尾按 `(x,y,Tick)` 哈希上升/摇曳（50% 正上、25% 左上、25% 右上，被挡不下降；`OnMotion` 留空）。**shade 是温度分档派生量**（≥300 亮黄 … <40 暗红，+哈希 ±1 抖动）。
- 显式行为：火无法停留在石头/沙/水面上（压顶立灭的推论，是设计）；落不可燃物上很快熄、只有燃料能持续供火、被埋死/封密闭腔当帧窒息。
- 投放资格（`FireParticle.CanPlaceAt`）：只在空气/气体格、不覆盖实体，无附着/悬空限制。水/沙置换即灭（世界规则涌现）。

## 树木三件套（树木种子 / 树干 / 树叶）

物种编号在 flags bit3-5（五物种：杨/橡/松/柏/柳，参数见 `TreeSpecies` 静态表——H 树干高 / N 生长分母 / D 发芽分母 / 基质档 / 树冠有序偏移表 / 支撑半径）；树干 bit6-7 = 生长阶段、树木种子 bit6-7 = 空转计数、树叶 bit6 = 失活标记（同组位按「一格一类型」互斥）。

- **树木种子**：受重力固体粉末。随机刻命中且「正上方非固非液 + 正下方按物种基质档（松/柏耐旱＝任意三土；杨/橡喜湿＝三土且八邻有湿土或腐殖土；柳最喜水＝正下方湿土/湿润腐殖土/腐殖土）」按 **1/D** 发芽（掷骰未中不计打击）。腐殖土是决定性基质时发芽成功消耗脚下土层最深一格腐殖土家族；松/柏永不消耗。3 次无发芽条件霉烂成腐殖质（条件满足时先清零计数再摇骰——「连续」语义）。
- **树干**：每逻辑帧逐格死亡判定（失去扎根〔下格非三土/沙/树干〕→ 本格与上方整段级联 `Clear`，清完再逐格调 `TreeLeafParticle.NotifyTrunkRemoved` 让整冠当帧集体失活——随机刻关闭时砍树也当帧生效；温度 > 50 死；低温致死 0）+ 顶格生长：阶段 0 按 H 向上爬（正上方是树叶可顶开穿冠，石头/水/沙硬阻塞；正上方越界即封顶转造冠）、阶段 1 按偏移表取「第一个未填充且当前可放」的项 `Set` 成树叶（可放＝非固液 + 八邻已有未失活树格；被挡项跳过不卡死、腾空补长；越界项视为已填充；填满转阶段 2 成熟并把 StageMature 沿树干列向下传播到底——成熟即整柱熟态，被腰斩留不再生树桩；StageCanopy 不传播）。
- **繁殖**：成熟顶格每次随机刻命中摇 1 骰（`NextUInt() % 4`），摇中在以顶格为中心半径 5 圆盘内按固定序（y 升序、同行 x 升序）找第一个「空地 + 正下方可托住种子的固体（固体且非树木三件套）」撒一颗同物种种子；非顶格/未成熟格零随机流。
- **树叶**：`OnLogic` 空。随机刻里：已失活 → `Clear`；否则 ① 温度 > 50、② 正上方被固体（非树叶）压 → 当帧死；③ 支撑半径内无树干 → 记录失活（bit6）并立刻让八邻树叶各自检测支撑（失活扩散——砍树后整冠一瞬间集体失活）；同一判据也由 `NotifyTrunkRemoved` 主动触发。失活叶 `OnMotion` 竖直自由下落一格（不滚落；只有正下方是空气/气体才落；叶密度 0.6 < 水 ⇒ 落叶浮水面不沉底），落稳后等随机刻收尸。失活后就地改 flags 故调 `ParticleWorld.WakeMotion` 唤醒运动休眠。三件套都 Solid + Organic，死亡按 20% 留腐殖质；树叶/树干是火的燃料。
- **雨水穿冠**：水格正下方是树叶时沿本列连续叶柱（≤ `WaterParticle.CanopyPassMaxDepth` = 8）竖直扫到第一格非树叶，是气体就 `Swap` 送到冠下（`WaterParticle.TryPassThroughCanopy`，运动路径零随机流；水的运动阅读盒下沿扩为 down = 9，写入唤醒并集 87 → 151 格）。
- 树干/树叶不可手刷，树木种子单颗投放 + Shift+滚轮切物种。

## 雷电

气体（密度 1.0 = 最重气体，环境大气推不动它；热学参数与大气同值——不注热/不挡光，热效应由落点火负责）。不可手刷，只能由模拟起爆。

- 起爆门挂在大气随机刻：命中空气格先摇 **2%** 骰（每次命中恰耗 1 个随机数），再要求半径 3 圆盘（29 格）总湿度 ≥ 3.0（≈ 每格 0.103，只有蒸发上限吃满的厚雨云压得到），随后起爆：自本格向下逐行铺一整条主干（每行 x 按 `(x,y,Tick)` 坐标哈希 ±1 抖动，50% 直落/25% 左/25% 右，两个独立 salt 位、不耗随机流），遇非气体格即止——那是落点，固/液从不被覆盖——并在落点上方那排（x ± 1）把气体格 `Set` 成火；整列都是气体则不生成火。
- `Cell.shade` 即闪光档（`OnSpawn` 钉 0 = 最亮白热核心，调色板白热→亮黄→黄→暗琥珀 4 档 = `LifetimeTicks`），`OnLogic` 每帧推进一档、末档 `Clear`（≈0.2 秒）——整条同帧起爆故一起明灭。不占 flags 私有位、`OnMotion` 空。
- 频率（实测 320×180、随机刻 48、24000 逻辑帧）：全海洋正午 ≈ 0.24 道/秒、混合地形 ≈ 0.13 道/秒、干燥场景 0；云越厚打雷越密。

## 生物质

动物尸体的物质化产物，`Solid` 且**刻意不带 Organic**（自带 70% 腐殖质 / 30% 散失的腐败流程）。颜色索引占 `Cell.shade`、落稳计数占 flags bit3-7（饱和 31）。落稳 31 帧后每逻辑帧 1/200 摇腐败 → 70% 腐殖质 / 30% 散失。只在注册表最后追加。

## 冰（水 ⇄ 冰相变）

水的固态形态：`Solid`、**不带 Organic**、不受重力。不用 `IsStatic`（静态类型收不到随机刻，而冰要靠随机刻融化），靠空 `OnMotion` 原地不动；`OnLogic` 严格空体（`hasLogic: false`）。**不可手刷**，只能由水在低温下冻结。热学：热容 3.5（水 6.5 的一半）、导热 0.85、辐射率 1.0（暴露冰面夜间继续抽冷 ⇒ 驱动加厚）、光吸收 0.4（反光）；调色板 4 档淡蓝白；`HasOutline` + **`OutlineLighten` 浅色描边**（向 `OutlineLightColor` 提亮，与其它固体的调暗相反）。细节见 `docs/ParticleTypeInterface.md` §6「水 ⇄ 冰相变」。

- **结冰**（`WaterParticle.OnRandomTick` 冷端分支，**随机刻驱动**、钩子里不再叠概率骰；与蒸发的热端 ≥ 20 区间不相交）：水面 = 正上方**界内**气体/空 + 正下方落定（顶行 / 悬空水滴不冻）。无冰邻格要过冷到 **3.5**（`FreezingPoint − NucleationSupercooling`）**成核**；挨着冰照 **4.0** **蔓延**；冰下按**几何梯度** `4.0·0.5^d` **加厚**（d = 正上方连续冰格数 `DepthBelowIceTop`，`ColumnScanDepth` = 8 封顶；越深越接近环境 0 ⇒ 厚度无上限，只是越深越慢）。
- **融化**（`IceParticle.OnRandomTick`，镜像；命中即判、不叠概率门）：`T ≥ 6.0 + 2.0·d`（线性、越深越难融）⇒ 当帧化回水。
- **光照冷度缩放**（`WaterParticle.LightColdScale`）：整条门槛乘光照面板的**强度**——8~12 平坦 ×1、更弱线性升到 ×1.2（0 处）、更强线性降到 ×0.6（24 处饱和）；结冰侧与融化侧共用同一缩放（迟滞带 4.0~6.0 整体缩放，防同一格反复相变）。看**配置强度**而非瞬时亮度。
- **潜热与热容差**：`SetPhase` 保留 Q 而 T = Q/热容，故先结算热容差 `ΔC·T`（ΔC = 3.0，保温度连续），再按本相热容加减潜热（结冰 `+C_冰·s` 放热 / 融化 `−C_水·s` 吸热，s = `FusionTemperatureStep` = 1.0）⇒ **冻融往返逐位守恒**（两侧用同一个 Q 常数会净产热）。世界未注册冰时整段跳过（`IsRegisteredIn`：隔离类型表世界里不结冰、不耗随机流、不打 error）。
- 涌现：冰挡光 ⇒ 冰下水不蒸发 / 不辐射散热 / 对流被盖住；冻湖写进 `CreatureTerrain.IsSolid`（可走）但 `CreatureDeathMaterializer.CanCorpseOccupy` 显式排除（尸体不得覆盖冰，否则水账漏一份水）；冰是固体 ⇒ 压死正下方的水生植物（该格还水，守恒不破）；火不认冰（贴非可燃固体 1/5 熄），但火加热冰会让它自己融掉。

## 投放白名单（编辑器）

草/花/湿土/腐殖质/腐殖土/湿润腐殖土/水生植物/树干/树叶/生物质/**冰**不可选（白名单改动要 C# 默认值与 `MainScene.unity` 的场景序列化名单**两处同步**——运行时以场景为准）；草种子/树木种子单颗投放 + 500ms 冷却；火经 Gas 白名单 `_placeableGasTypes` 例外可手刷（受 `CanPlaceAt` 约束）；雷电不可手刷。详见 `docs/modules/DriverAndEditor.md`。
