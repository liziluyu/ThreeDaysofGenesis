# 动物实体层（Creatures）

`Assets/Scripts/Simulation/Creatures/`，与粒子世界并列、同线程、逻辑帧 20 Hz。架构与数值的权威文档是 **`docs/design-creature-ai.md`**；生态扩展计划见 `docs/plan-creature-ecology.md`、鸟方案见 `docs/plan-bird-ai.md`、**繁殖方案见 `docs/plan-creature-reproduction.md`**、**衰老方案见 `docs/plan-creature-aging.md`**（§25，已实现）。

## 骨架

- `CreatureWorld`：实体表 + **独立 xorshift32**——动物绝不消耗世界随机流；事件 `CreatureSpawned`/`CreatureDied` 供同线程监听者（测试 / 未来的遗骸生成）使用，**跨线程消费者走帧**：出生 / 死亡另按物种计数（`Spawn` / 清扫阶段自增），由帧采集 `ConsumeEvents` 抽干成 `AudioFrame.CreatureSpawnCount` / `CreatureDeathCount`（见 `docs/modules/SimulationCore.md`、`docs/modules/DriverAndEditor.md`）。
- `Creature` 抽象基类（相当于粒子体系的 `IParticleType`）：物种差异走虚属性——`Gravity`/`MaxFallSpeed`/`Buoyancy`/`WaterDrag`/`FliesInAir`/`PerchesOnFoliage`/`FlyAccel`/`PlaceholderColor`；钩子 `OnSpawn`/`OnLogic`（物理之前，AI 决策入口）/`OnDeath`。
- `CreatureTerrain` 碰撞白名单：**只有沙/石头/泥土家族（土、湿土、腐殖土、湿润腐殖土）与冰挡动物**，水是淹没/浮力介质，草花叶树种子一律穿过；鸟另有栖息面口径 `IsPerchable` = IsSolid ∪ 树叶/树干（只服务向下支撑）。冰在死亡物质化那侧是**显式例外**（尸体不得覆盖冰，见下）。
- 实体 = 连续浮点位置（`X, Y` = 碰撞盒底边中点，单位格）+ 轴分离 AABB 物理（重力 → 竖直逐行扫 → 水平 → 边界夹取 → 刷新 `IsGrounded`/`IsSubmerged`）。物理与感知对粒子世界只读；四处写入例外：**兔子进食**（`world.Clear` 一格草或花）、**鱼进食**（`world.Clear` 水草顶端一格）、**鸟进食**（`world.Clear` 一格生物质）与**死亡物质化**，都走世界 API，不得直接改 `_cells`。
- 驱动在每个 `StepLogic()` 之后调 `Creatures.Step(world)`（高速会话转发之前）。

## 物种

- **兔**（陆生验证体）：**寿命 5200 逻辑帧（260 秒）**后老死 `OldAge`（`LifespanTicks`，2026-10-17）；被鸟扑中时 **1/2** 概率死亡（`HuntDeathRoll = 2`，§14）。
- **鱼**（水生，**中性浮力** `Buoyancy = Gravity`）：体顶之上那格不是水（体顶 = floor(Y) + `BodyTopOffsetCells`，尺寸来自 `CreatureArtData.Fish`）就锁潜下潜、体顶之上连续 3 格全水才解锁、离底 2 格内上浮 ⇒ 水深 ≥ 7 格整条没入水下并进**深度带随机上下游**（v6 §15：目标深度 = 体顶之上连续水格数 ∈ `[3, min(8, 水深 − 4)]`，到达即重摇 ⇒ 5 格振幅内缓漂），`geoMax = 水深 − 4 < 3` 的浅池整段跳过（行为与从前一字不变、零额外摇骰）⇒ d ≤ 6 永久锁潜贴底（停水平意图、不撞坎掉头）。水平为墙感知换向——前方 3 格体高行内全水保持方向不摇骰、受阻才 1/3 摇骰；**游速 0.1 格/帧**（2026-10-17 用户要求 ×2，原 0.05）。**饥饿时觅食水草**（2026-10-17）：`HungerTicks >= 600` 且冷却 0 时在半径 6 内找最近的、八邻有水的水生植物（`FindNearestAquaticPlant`，固定扫描序、零随机数），水平/竖直逼近直到相邻一格，咬掉**整株最顶一格**（底段保留）、恢复 420 帧饥饿并进 20 帧冷却；附近没有水草时照常巡游；鱼**会饿死**（`StarvesWithoutFood = true`，2026-10-17）：饥饿饱和 1200 帧（≈60 秒）→ `Starved`。被鸟扑中时 **1/3** 概率死亡（`HuntDeathRoll = 3`，§14）；**寿命 6400 逻辑帧（320 秒）**后老死 `OldAge`（`LifespanTicks`，2026-10-17）。
- **鸟**（飞行，`FliesInAir`：空中挂起重力、可悬停；`FlyAccel` 驱动空中竖直意图，落地/入水恢复常规）：六态 `BirdBrain` = Perched/Fly/Flee/**Hunt**/**SeekFood**/**Eat**（v9 §19：饥饿且 `world.BiomassCount > 0` 时先找并吃生物质，世界没有生物质才回到 Hunt；仍不饿死）——栖息计时起飞、**随机目标高度的上下巡航**（v3/v4/v8：以正下方第一个可栖面/水为基准，目标高度随机、到达即重摇 ⇒ 越过高地形后主动回落、消除旧的单向棘轮；**名义带顶 50 格，逐图按可达净空钳制** `maxAltitude = max(6, min(50, 世界高 − 12 − 1 − 地表行))` ⇒ 脚底 ≤ min(地表行+51, 88)，天花板 `Y > 世界高 − 12` 是硬边界，探不到基准则悬停）、计时降落**树叶/树干**（v7 §17：地面虽可站但**不落**；`LandProbeCells = 24` 且**不随带顶放大** ⇒ 只有漂低时才降）、火威胁逃命（同兔滞回 + 最短时长，可打断 Hunt）、落水正浮力上浮自救、墙感知换向同鱼。**Hunt（捕食，v2；死亡骰 v5，§14）**：Fly 思考帧视野 24 格内（**§18 起不随带顶 50 放大** ⇒ 高度 > 24 时看不见地面猎物，只有漂低才捕食）有兔/鱼才摇 1/40 骰（无猎物不摇骰、随机流不漂移）⇒ 追击（降落同款重瞄活动目标，下压用 `HuntDiveSpeed = 0.2`）⇒ **锁定目标那一刻再摇一次死亡骰**（`1 / HuntDeathDenominator`，兔 1/2、鱼 1/3）并锁存到 `HuntKillLatched`——追击动作不变；碰撞盒接触时由运动层 ⑥b **只读锁存**结算（零随机数依赖）：命中判死（死因 `Hunted`，尸体走既有物质化）、扑空则猎物**无伤**（生物质零增量），两种情况都即刻清空目标 ⇒ 杀完 / 扑空都起飞离开不停留；追丢（>32 格）/超时（200 帧 ≈ 10 秒）放弃；目标是鱼时可短暂俯冲入水（豁免落水自救反射，溺死兜底不变）；猎物 v1 无天敌感知。

## AI（v1）

静态无状态 Brain（`RabbitBrain` = Idle/Wander/Flee/SeekFood/Eat、`FishBrain` = Swim/Stranded（**饥饿觅食是 Swim 的子行为**，2026-10-17）、`BirdBrain` = Perched/Fly/Flee/Hunt/SeekFood/Eat）+ 基类内联黑板槽位（`AiState`/`StateTicksLeft`/`SensePhase`/`IntentVx`/`IntentVy`/`WantHop`/`VerticalDiveLatched`/`HuntTarget`/`HuntKillLatched`/`TargetAltitudeCells`/`TargetDepthCells`/`Sex`/`BreedCooldownTicks`/`PreyEaten`/淹没与离水计时）+ `ShouldThink` 门控（**每 10 逻辑帧 = 2 Hz**，相位 `SensePhase = 生成序号 % 10` 由 `Spawn` 钉死 ⇒ 错峰、死亡移除不改他者相位）+ 运动层 `ApplyLocomotion`（每逻辑帧夹在 `OnLogic` 与 `StepPhysics` 之间：意图→速度加速度限幅、朝向迟滞、悬崖守卫〔Flee 豁免〕、撞墙跨坎（`CanStepUp`：兔子 true/鱼 false；不可翻越掉头；顶世界边界也掉头）、接触火即死 `Burned`、身体被静止固体全覆盖 10 帧压死 `Crushed`〔门控 `DiesWhenBuried`〕、连续淹没 `DrownTicksLimit` 溺死 `Drowned`〔兔〕/连续离水 200 帧搁浅死 `Beached`〔鱼〕/`AgeTicks` 达寿命老死 `OldAge`〔三物种，门控 `MaxAgeTicks`〕）+ `CreatureSensors`（固定扫描序只读探针：半径 `Creature.ThreatRadius` = **16** 圆盘威胁扫描仅思考帧——逃命取最近的火定方向，有滞回（进入 16、脱离 +`FleeExitMargin`）与最短逃命时长 `FleeMinTicks`；火与兔同列时只在刚进入逃命那一刻摇一次方向；地面/墙探针每帧 O(1)）。

**RNG 纪律**：决策只吃 `creatures.NextInt` 且只在思考帧消耗（含**锁定猎物那一刻**的死亡骰 §14、鱼的**到达目标深度时**的重摇 §15；浅池不进带内路径 ⇒ 零额外摇骰）⇒ 加动物不扰动粒子世界随机流；**例外**：死亡物质化与兔子进食写格消耗世界随机流（它们是粒子世界内容）；鸟吃生物质 / **鱼吃水草**同样写格，但两者都不带 Organic 且 `Clear` 到空气不抽 shade ⇒ **不消耗世界随机流**——「有动物 vs 无动物逐位一致」只在无死亡、无（兔）进食场景成立。
- **繁殖（v1，2026-10-17，方案见 `docs/plan-creature-reproduction.md`）**：**两性配对**——需要**相邻的异性同类**（中心距离 ≤ 2）、双方成年（`AgeTicks`）与冷却（`BreedCooldownTicks`）满足、物种条件满足、未到软上限；**只有雌性**在思考帧摇一次骰（`NextInt`），命中后**入队** `RequestBirth(母, 父)`，`Step` 在**死亡清扫之后**统一 `Spawn`（新生儿**本帧不推进**、`AgeTicks = 0`、带初始冷却）。性别由**生成序号奇偶**钉死（`Sex`，与 `SensePhase` 共用同一序号、不摇骰）。软上限 **兔 12 / 鱼 12 / 鸟 4**，低于下限（2/2/1）概率 ×2，概率随 `(上限 − 数量) / 上限` 线性衰减。物种条件：兔 = 雌性刚吃过（`HungerTicks < 300`）；鱼 = 双方完全没入水下且**所在连续水柱**深度 ≥ 7；鸟（最慢：成年 60 s、冷却 150 s）= 双方各 ≥ 1 次捕食成功（`PreyEaten`，运动层 ⑥b 击杀时 +1）且不在 Flee/Hunt。**出生不消耗世界物质**（用户口径，物质守恒列为已知取舍）。

## 生态交互

- **饥饿与食草**（兔）：`HungerTicks` 每逻辑帧 +1、饱和 `MaxHungerTicks` = 1200（≈60 秒）；只有 `StarvesWithoutFood` 为真的物种〔兔〕饿死 → `Starved`。超过 `HungryThreshold`（600）且进食冷却为 0 进入觅食——`SeekFood` 用 `FindNearestGrassOrFlower`（半径 6 圆盘、固定扫描序、取最近）选目标，进到相邻一格转 `Eat`，按固定顺序（正下→正前→正上→左→右）找第一格可食植物（草 / 花）`Clear`（一次只吃一格、恢复 `FoodRestoreTicks` 并进 20 帧冷却；食谱 = 草与花，不吃草种子 / 腐殖质 / 土壤；目标连续 40 思考帧不可达放弃）。火焰威胁优先于饥饿。
- **饥饿与食水草**（鱼，2026-10-17）：与兔子同门槛/恢复量（`HungryThreshold` 600、`FoodRestoreTicks` 420、冷却 20 帧、放弃上限 40 思考帧）。饥饿是 **Swim 的子行为**（不新增 `AiState`）：思考帧在常规巡游**之前**用 `FindNearestAquaticPlant`（半径 6 圆盘、固定扫描序、取最近；候选格八邻必须有水 ⇒ 不追露出水面的枯草）选目标，水平以 `SwimSpeed`（0.1 格/帧）追目标列、竖直朝目标行逼近（上浮受「体顶之上仍是水」门控），进入水平/竖直各 ≤ 1 格即进食。进食写入 = `world.Clear` **整株最顶那一格**（自被咬中的茎格沿本列向上找到连续水草顶端；底段保留、水草可继续生长；水生植物不带 Organic，`OnKill` 把那份水注入邻格湿度场）。附近没有水草时照常巡游；**饥饿饱和 1200 帧（≈60 秒）即饿死**（`StarvesWithoutFood = true`，2026-10-17 用户要求，死因 `Starved`）。
- **饥饿与食生物质**（鸟，v9 §19）：`HungerTicks >= 600` 且冷却为 0 时，先看 `world.BiomassCount`（`ParticleWorld` 由 `ParticleCountMonitor` 在生物质产生 / 消失时 O(1) 维护）：> 0 就 `SeekFood`（`FindNearestBiomass` 半径 24、固定扫描序、取最近）→ 相邻转 `Eat`，按固定顺序 `world.Clear` 一格生物质、恢复 420 帧饥饿并进 20 帧冷却 → 起飞；世界没有生物质时才走既有捕猎。追击已开始的 Hunt 不因饥饿中断；有生物质但 24 格内没有时继续巡航搜索且不触发捕食。鸟仍不因饥饿而死。
- **衰老死亡**（2026-10-17）：每只动物有固定寿命，`AgeTicks` 达到物种 `LifespanTicks` 即 `Kill(CreatureDeathCause.OldAge)`——**确定性、零随机数、不做个体抖动**；判定是运动层 `ApplyLocomotion` 的最后一段（排在火 / 压 / 溺 / 搁浅 / 饿之后 ⇒ 同帧多因时优先报更具体的近因），代价是每帧一次比较。门控是基类虚属性 `MaxAgeTicks`（**默认 0 = 永不老死**，测试探针与未接线物种零行为差异）。寿命：**兔 5200 / 鱼 6400 / 鸟 12000** 逻辑帧（260 / 320 / 600 秒）——由实测标定（食物充足时成对出生间隔兔 405 / 鱼 600 / 鸟 3025 帧，兔的种群平衡扫描在 4800~12000 稳定、≤3600 会随机灭绝），详见 `docs/plan-creature-aging.md`。老死复用既有死亡链（清扫 → 生物质 → `OnDeath` / `CreatureDied` → 帧里的物种死亡计数），因此声音 / 统计 / 尸体零改动。
- **死亡物质化**：死亡清扫先由 `CreatureDeathMaterializer` 按 `BiomassProfile`（轮廓由编辑器菜单 `Tools/Animals/Regenerate Creature Art Data` 从 PNG + 切片 pivot 生成 `CreatureArtData.g.cs`——当前兔 22 格/鱼 22 格/鸟 61 格；`CreatureArtDataTests` 对拍守卫，美术变更后忘重跑即红；映射 `x = floor(X) − 8 + dx`、`y = floor(Y) − PivotRowPixels + dy` ⇒ 尸体与渲染身体逐格对齐）用 `SetWithShade` 逐格写生物质（空气/气体/草花叶 + 地形固体可覆盖——**冰除外**：冰算地形但不可被尸体覆盖，否则水账漏一份水；**水先 `Swap` 挪到合格空位再写、挪不动跳过该格**（绝不删水 ⇒ 水守恒）；火/树干/已有生物质/越界跳过），**再**发 `OnDeath`/`CreatureDied`（顺序即契约）。生物质随后作为普通粒子下落堆积、腐败（见 Particles 文档）。

## 时间尺度

空中运动：重力 0.24 格/帧² + 终端速度 2.4/1.2 格/帧（比初版 0.08/0.8/0.4 快 3 倍、同比缩放 ⇒ 运动形状不变；只提重力无效——终端速度才是落体上限）。水中速率经 `Buoyancy` 重算后与初版逐位一致（兔 0.18 格/帧沉；鱼中性浮力 ⇒ 深度由意图维持）。
