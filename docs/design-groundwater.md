# 地下水：静止固体不能置换液体（v2）

> 状态：**已实施**（2026-10-09；离线全量 282/282 通过，待真机复跑）。v1「左右被夹住」规则经离线实测发现保不住画刷形状水囊与联通池塘的地下水（台阶拐角处石头借水囊自己的水当旁路，逐格塌入、水被抽上来），已废弃，改为本版。
> 范围：`ParticleWorld`（逐格运动状态）+ `ParticleRules.CanDisplace`（闸门）；不改 `Cell` 布局、注册表、渲染管线、驱动。
> 实施完成后：把定稿行为回写 `docs/ParticleTypeInterface.md` 与 `AGENTS.md`，本文件转为历史记录。

## 1. 修改内容

### 1.1 规则：只有「运动中」的固体能排开液体

> **固体置换液体前，该固体必须处于运动中**——上一运动扫描位移过，或本帧新放置（见 1.3）。

- **挂载点**：`ParticleRules.CanDisplace`（全工程唯一的置换闸门）。直落 `TryFall` 与固体斜落 `TrySlide`（净空链逐格）同时受约束。
- **触发条件**：`TagRank(self) > LiquidRank && 目标带 Liquid 标签`。只有「固体 → 液体」被约束；液体→气体、固体→气体、气体运动、火 / 水蒸气照旧。
- **开关**：`ParticleWorld.GroundwaterSealingEnabled`（默认 `true`）。置 `false` 时跳过本判定、退回旧的 rank 置换行为（A/B 对照与回归验证）。运行期切换会整张置位运动候选位图。

```
CanDisplace(from=(x,y), to):
    if 目标越界: return false
    if 目标 typeId == 空气: return true
    if (rank(self) > LiquidRank && 目标带 Liquid && world.GroundwaterSealingEnabled):
        if 固体不在运动中: return false
    return rank(self) > rank(other)               // 既有行为，不变
```

### 1.2 只改液体，气体照旧

封闭在固体里的空气泡 / 水蒸气仍会被上方固体置换而冒泡上升。密封水囊沸腾成汽后，蒸汽仍能逐格穿石逸出。

### 1.3 运动状态的维护

- 世界持两张逐格标志位图（双缓冲）：每轮扫描开始时交换 live ↔ pending 并清空 pending。
- **判定**：`HasMomentum(x, y)` ⟺ live 位置位（= 上一扫描位移过，或上一扫描之后放置过）。**显式过期、不看 `Tick`、无模运算**——时间函数式判定（序号按模比较）会带来「幽灵动量」：旧值回绕成"刚运动过"、无需任何写入即翻真，休眠路径与全扫路径由此发散（实测每 256 扫描咬一次）。
- **写入**：
  - `Swap`：两端格置位；**有固体向下换位**时另置位该固体原格的正上方（= 下一步会跟随落下的同伴）。纯液体 / 气体换位（水↔水对流、横流、气体上升）**不置位**——否则池面对流的静止石板会被拖下水。
  - `Set` / `SetPhase`：新位置位（`_tick > 0` 时——**构造期 tick 0 的初始条件一律视作静止**，不给宽限：用 `Set` 搭出来的场景第一帧不许自行塌陷）；运行中放置 / 相变的物质视作运动中，画笔直接放进水里的沙石照旧下沉。
- **过期与求值无关**：标志只按扫描轮换，休眠粒子不会被"消费掉"动量——这是休眠透明性的前提。
- **唤醒**：所有置位点都伴随候选唤醒（写入唤醒并集覆盖被换格正上方，含同帧 `MarkCandidatesThisScan`）。

## 2. 效果

| 场景 | 行为 |
|---|---|
| 石头 / 沙里的水囊（单格、多格、画刷形状、含台阶斜边） | 逐位不动（周围固体从未移动）。**土例外**：干土会按既有土壤反应把正上方的水吸成湿土——土 / 湿土现有行为一律不动，也不要求土实现「地下水」效果 |
| 与水囊同层相邻的水、通到池塘的窄缝 / 竖井 | 同理不动；岩石塌不进去 |
| 池塘里下落 / 倾倒的沙石（单颗、成排、整块） | 照旧下沉、水位上升（下落本身就是运动） |
| 沙倒进一格宽石竖井 | 照旧沉底、水被挤上来（v1 的「活塞卡住」代价消失） |
| 主动丢进裂缝 / 竖井的沙石 | 会 1:1 挤开地下水（相当于打井填沙；物理上就是有物质进入） |
| 挖开包围的水囊 | 水由自身流动排出（水不受本闸门约束） |
| 封闭气穴 / 水蒸气 / 沸水成汽 | 照旧冒泡上升、穿石逸出（§1.2） |
| 刚用画刷直接放进水里的沙 / 石 | 照旧下沉（新放置视作运动中） |
| 停在水中的石块（下方支撑被移走） | 不再自行下沉（静止即稳定）——已知取舍见 §4 |

## 3. 工程影响

- **性能**：`CanDisplace` 的固体→液体路径多一次字节数组读；写路径（`Swap`/`Set`/`SetPhase`）多 2~4 次字节写。热路径零分配不变。
- **确定性**：新状态只由写入原语确定性更新，零随机流消耗。
- **运动休眠**：新判定读本格自身的状态位（写路径已维护），标记传播的格（被换格正上方）在写入唤醒并集内（粉末 `MotionReadReach` 反转后覆盖同行侧邻与上方）。休眠 on/off 逐位一致由既有 A/B 回归与新增用例守护。
- **代码面**：`ParticleWorld`（状态数组 + `HasMomentum` + 写路径标记）、`ParticleRules`（闸门，替换 v1 的 `HasLateralEscape`/`IsOpenSide`）。

## 4. 已知取舍（接受）

- **静止即稳定**：下方支撑被移走的悬空石块不会自行再沉（它已静止）；任何本地写入会唤醒它，但只有再次运动才会重新获得排开液体的能力。现实中罕见，接受。
- **新放置视作运动中**：画刷直接放进水里的石头会像丢进去一样下沉（与旧行为一致）；用画刷在水面上方搭的薄石板会像旧版一样塌入水中（本规则只阻止"静止物质自行开始运动"，不改变"刚放置 / 运动中的物质"行为）。
- 不影响：开阔池塘、雨、河流、海陆风、水循环等一切开放水域行为。

## 5. 测试计划

| 用例 | 断言 |
|---|---|
| `CanDisplace` 单元（隔离类型表） | 静止固体 → 置换液体不成立；上一扫描位移过的固体 → 成立；`Set` 刚落下的固体 → 成立（宽限）；目标为气体 → 不受影响；开关关 → 退回旧行为 |
| 水囊稳定 | 石头中 3×3 水囊 + 画刷形状水囊，跑 120 周期 `Cell[]` 逐位不变（哈希比较） |
| 竖井活塞回归（改回） | 一格宽石竖井：沙照旧沉底、水被置换上浮（恢复原 `Sand_SinksThrough_Water`） |
| 开阔水域下沉 | 单颗沙 / 3×3 沙块沉底、水位抬高、守恒 |
| 联通地下水 | 水囊 + 一格宽竖井 + 池塘；丢沙入池塘 → 沙沿竖井沉到底、水囊不被扰动（石块不塌） |
| 挖开释放 | `Clear` 一侧石壁 → 水由自身流动排出到竖井 |
| 运动休眠 A/B | 同场景 `MotionSleepEnabled` on/off 逐位一致 |
| 气体不受影响 | 石中气穴照旧冒泡上升 |
| 全量回归 | 既有 EditMode 用例全部通过（离线通道全量 + 用户真机复跑） |
