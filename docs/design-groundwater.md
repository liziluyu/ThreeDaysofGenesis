# 地下水：封闭液体不被固体置换（v1）

> 状态：已定稿待实施（2026-10-09）。
> 范围：`ParticleRules.CanDisplace` 一处判定 + `ParticleWorld` 一个开关；不改 `Cell` 布局、注册表、渲染管线、驱动。
> 实施完成后：把定稿行为回写 `docs/ParticleTypeInterface.md` 与 `AGENTS.md`，本文件转为历史记录。

## 1. 修改内容

### 1.1 规则：局部「被夹住」判定

> **固体置换液体前，检查它左右两侧（同一行 `x±1`）：若两侧都被固体堵住（越界按固体算），这次置换不成立。**

- **挂载点**：`ParticleRules.CanDisplace`（全工程唯一的置换闸门）。直落 `TryFall` 与固体斜落 `TrySlide`（净空链逐格）因此同时受约束。
- **触发条件**：`TagRank(self) > LiquidRank && 目标带 Liquid 标签`。只有「固体 → 液体」被约束；液体→气体、固体→气体、气体运动、火 / 水蒸气照旧。
- **判定读距**：`(x±1, y)`（下落者自身一行）。

```
CanDisplace(from=(x,y), to):
    if 目标越界: return false
    if 目标 typeId == 空气: return true
    if (rank(self) > LiquidRank && 目标带 Liquid && world.GroundwaterSealingEnabled):
        if 左侧被堵 && 右侧被堵: return false     // HasLateralEscape == false
    return rank(self) > rank(other)               // 既有行为，不变
```

- 「被堵」= 越界或带 `Solid` 标签；旁路 = 液体 / 气体 / 空（`HasLateralEscape(world, x, y)`：左右至少一侧不是固体且不越界）。
- **开关**：`ParticleWorld.GroundwaterSealingEnabled`（默认 `true`）。置 `false` 时跳过本判定、退回旧行为（A/B 对照惯例，同 `MotionSleepEnabled`）。

### 1.2 只改液体，气体照旧

封闭在固体里的空气泡 / 水蒸气仍会被上方固体置换而冒泡上升（现状不变）。密封水囊沸腾成汽后，蒸汽仍能逐格穿石逸出。

## 2. 效果

| 场景 | 行为 |
|---|---|
| 石头 / 沙 / 土里的水囊（单格、多格、画刷形状） | 逐位不动 |
| 水囊的**拐角** | 石板无法斜滑进入（斜落同样过 `CanDisplace`） |
| 与池塘联通的窄缝 / 隧道 | 通道里的水与囊里的水都不动；沙石停在通道口 |
| 挖开一侧石壁 | 被夹条件不再成立 → 水从缺口流出 / 被置换（规则纯读取，无状态） |
| 开阔池塘 / 湖泊 / 雨 | 照旧：沙石下沉、水位上升、横流摊平（下落者左右是水 → 不算被夹） |
| 成排 / 整块下落的沙（淹没在水里的沙堆） | 照旧整体下沉（同行相邻格先落者腾出的格子已由被置换的水占据，后落者一侧是水） |
| 封闭气穴 / 水蒸气 / 沸水成汽 | 照旧冒泡上升、穿石逸出（§1.2） |
| 液面下的石柱（两侧是水） | 照旧下沉 |

## 3. 工程影响

- **性能**：仅「固体 → 液体」置换时多一次标签判断 + 最多两次邻格读；热路径零分配不变。
- **确定性**：纯读取当前网格、无新增状态、零随机流消耗 → 同种子同命令逐位可复现不受影响。
- **运动休眠**：新判定读 `(x±1, y)`，必须在写入唤醒并集的该行半宽之内。实施时逐类型核对 `MotionReadReach` 的声明（固体都走 `StepSolid`、本就声明同行侧邻；须确认并集覆盖 `dy = 0` 的行）并补休眠 on/off 逐位一致回归。
- **代码面**：`ParticleRules`（判定 + 注释契约）、`ParticleWorld`（开关属性）、相关文档注释。

## 4. 已知取舍（接受）

- **活塞效应**：铺满固体通道宽度的沙石（倒进石缸、竖井、窄裂缝）停在水面上——水出不去、沙下不来。现实里沙透水，本 CA 无孔隙渗流；未来新增「渗流」可解除。
- **1 格宽竖井（井）**里倒沙 → 沙停在水面上。现有 `Sand_SinksThrough_Water`（`WaterParticleTests.cs:238`）语义反转，需按新语义改写。
- **液面下恰好卡在两侧固体之间的石板 / 石条**不再下沉。
- 不影响：开阔池塘、雨、河流、海陆风、水循环等一切开放水域行为。

## 5. 测试计划

| 用例 | 断言 |
|---|---|
| `CanDisplace` 单元（隔离类型表） | 两侧固体 → false；一侧液体 / 气体 / 空 → true；两侧越界 → false；目标为气体 → true（不受影响）；开关关 → 退回旧行为 |
| 水囊稳定 | 石头中 3×3 水囊，跑 N 个 `StepLogic` + `StepMotion`，`Cell[]` 逐位不变（哈希比较） |
| 画刷水囊 | 更大、含斜边的水囊同样逐位不变 |
| 开阔水域下沉回归 | ≥3 格宽水池：沙沉底、水上升、沙与水各自守恒；单颗石头落水照旧沉底 |
| 整块沙下沉回归 | 淹没在水中的多行沙块（宽度**小于**水池）整体下沉、不被「夹住」卡死 |
| 改写 `Sand_SinksThrough_Water` | 1 格宽竖井：沙停在 (4,4)、水留在 y=1..3（新语义，注释标注「活塞效应」） |
| 联通地下水 | 水囊 + 1 格通道 + 池塘；倒沙入池塘 → 囊 / 通道水位不动、沙停在通道口 |
| 挖开释放 | `Clear` 一侧石壁后，水从缺口流出（若干帧后缺口出现水、水囊迁移） |
| 运动休眠 A/B | 同场景 `MotionSleepEnabled` on/off 逐位一致 |
| 气体不受影响（可选回归） | 石中气穴照旧冒泡上升 |
| 全量回归 | 286 个既有用例全部通过 |
